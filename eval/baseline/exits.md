# Out-of-chat exits

`key` means the landlord leaves the chat to enter an API key or similar secret. A Google sign-in or an Allow click is `not key`.

| Task | Exit | Label | Taken |
| --- | --- | --- | --- |
| full setup to publish | Texting secure setup (API key) | key | no |
| full setup to publish | Google Drive backup sign-in | not key | no |
| full setup to publish | Tour-update secure setup (routine address and key) | key | no |
| book a one-off tour | none | not key | no |
| answer a flagged question | none | not key | no |
| pause a unit | none | not key | no |
| export a day's audit | none | not key | no |
